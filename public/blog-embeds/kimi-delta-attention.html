A memory that edits itself

Every efficient method in this series traded something away. Kimi K3's engine, Kimi Delta Attention, is the assembly that gives the least back: a linear-attention state that uses the delta rule to edit its memory — read the old value, erase it, write the correction — with per-channel forgetting, hybridized with a full-attention layer every fourth block. It is the whole decade of attention research, converged.

Recall the two ends of the tradeoff. Linear attention and state-space models keep a fixed-size state — O(1) memory, O(n) compute — but their state was lossy: pure linear attention just adds each key–value pair into the state and never removes anything, so associations pile up in superposition and recall degrades. That weak recall is exactly why linear models lost to attention on tasks needing precise retrieval.

The frontier's fix, embodied in Kimi Delta Attention (KDA) — the linear core of Moonshot's Kimi Linear architecture and the 2.8-trillion-parameter Kimi K3 — is to make the fixed state editable. Instead of blindly accumulating, it uses the delta rule: an old idea from associative memory that updates a stored association by correcting its error rather than piling new on top of old.

The one idea

Treat the state SSS as a key–value memory. To store value vvv for key kkk, first read what is currently stored, S⊤kS^\top kS⊤k, compute the error v−S⊤kv - S^\top kv−S⊤k, and update SSS proportionally to that error — erasing the stale association and writing the correction. That is the delta rule. It turns a fixed-size linear-attention state into a genuinely editable memory, fixing the recall weakness that held linear models back.

Additive memory vs the delta rule

Pure linear attention builds its state by summing outer products — St=St−1+ϕ(kt) vt⊤S_t = S_{t-1} + \phi(k_t)\, v_t^\topSt​=St−1​+ϕ(kt​)vt⊤​ — so writing a new value for a key you have already seen just adds on top of the old one; the memory now returns a blur of both. The delta rule (Widrow & Hoff, adapted to linear transformers as DeltaNet) subtracts before it writes:

St=St−1+βt (vt−St−1⊤kt⏟prediction error) kt⊤.S_t = S_{t-1} + \beta_t\,\big(\underbrace{v_t - S_{t-1}^\top k_t}_{\text{prediction error}}\big)\,k_t^\top.St​=St−1​+βt​(prediction errorvt​−St−1⊤​kt​​​)kt⊤​.

The term St−1⊤ktS_{t-1}^\top k_tSt−1⊤​kt​ is what the memory currently returns for key ktk_tkt​; subtracting it removes the stale entry, and adding vtkt⊤v_t k_t^\topvt​kt⊤​ writes the fresh one. If the key is new, the error is just vtv_tvt​ and it behaves like ordinary linear attention; if the key was seen before, it overwrites cleanly instead of superposing. From DeltaNet to Kimi Delta Attention

The delta rule fixes overwriting, but a good memory also needs to forget gracefully — to let stale information decay. Gated DeltaNet (Yang et al., 2024, "improving Mamba2 with the delta rule") added a forget gate that multiplicatively decays the state, combining gating (rapid, adaptive erasure) with the delta rule (targeted correction) — two complementary controls over the same memory.

Kimi Delta Attention sharpens this with channel-wise gating: rather than one forget gate per head, each feature dimension of the state gets its own learned decay rate. Some channels hold information for a long time, others fade fast — a much finer temporal control over what the fixed-size memory keeps, which the Kimi Linear report shows improves both stability and long-context recall. Under the hood it runs a hardware-efficient chunkwise algorithm built on a specialized Diagonal-Plus-Low-Rank state transition, so all of this stays linear-time and GPU-friendly.

St=Diag(αt) St−1+βt (vt−St−1⊤kt) kt⊤,αt∈(0,1)d (per-channel forget).S_t = \mathrm{Diag}(\alpha_t)\,S_{t-1} + \beta_t\,(v_t - S_{t-1}^\top k_t)\,k_t^\top, \qquad \alpha_t \in (0,1)^{d}\ \text{(per-channel forget)}.St​=Diag(αt​)St−1​+βt​(vt​−St−1⊤​kt​)kt⊤​,αt​∈(0,1)d (per-channel forget).

Even a self-editing state is still a compressed memory. To get the last mile of exact recall, K3 does not go all-linear — it hybridizes.

The hybrid: 3 linear layers, then 1 full-attention layer

Kimi Linear interleaves KDA with full attention in a fixed ratio — 3 KDA layers to every 1 full-attention layer (using Multi-head Latent Attention for the full layer). The linear layers carry the cheap long-range mixing at O(n) compute and a constant-size state; the periodic full-attention layer supplies the exact, arbitrary-distance recall a compressed state can't guarantee. The report finds 3:1 the sweet spot between cost and expressivity — the concrete realization of the "mostly cheap, occasionally exact" instinct this whole series has been circling.

Why it beats full attention

The striking claim in the Kimi Linear report is not "as good as, but cheaper" — it is better. The hybrid outperformed a full-attention MLA baseline across short-context, long-context, and RL-scaling regimes: higher on MMLU, GSM8K, and coding, and on the RULER long-context benchmark (128K+) it scored 84.3 versus 81.3 for the pure-MLA baseline — while using a fraction of the KV cache and running faster at long context. A well-designed editable-state hybrid does not merely approximate attention; on these evaluations it exceeds it.

And Kimi K3 Kimi K3 — Moonshot's open 2.8-trillion-parameter model — is built on this foundation: KDA linear layers interleaved with full attention, on top of a mixture-of-experts backbone, and combined with Attention Residuals across depth. It is not one clever trick but the assembly of nearly every idea in this series into a single system. (K3 is very recent, 2026; treat the mechanism as solid and the exact configuration details as still settling.)

The whole series, in one model

Step back and Kimi K3 reads as a catalogue of everything we built:

fixed-size statea running memory instead of a growing cache — from linear attention and SSMs
the delta ruleeditable associative memory that overwrites cleanly — fixing the recall weakness of a pure fixed state
channel-wise gatingcontent- and feature-dependent forgetting — the selection idea, made per-channel
hybrid + MLAoccasional full attention for exact recall, its cache shrunk by latent compression
hardware-aware kernelschunkwise, IO-efficient computation — the FlashAttention discipline
attention residualsattention across depth as well as tokens — from the residual-stream line

The quadratic wall that opened this arc set the whole field in motion; the frontier's answer is not a single escape but a synthesis — a cheap, self-editing, gated fixed state for the common case, punctuated by exact attention for the hard case, wired through a residual stream that is itself learned to attend. That is where attention research stands.

What it costs, and what's next

  • A compressed state is still compressed. The delta rule and gating narrow the recall gap but do not close it, which is exactly why the hybrid keeps full-attention layers. Pure-linear models still trail on the hardest exact-retrieval tasks.
  • The kernels are bespoke and the design space is churning. Chunkwise DPLR scans, decoupled erase/write (Gated DeltaNet-2), and new gating schemes are appearing fast; the "right" linear-attention recipe is not settled.
  • The frontier is very new. Kimi Linear and K3 are 2025–2026 work; the comparisons are early and evolving, and the pure-attention-plus-FlashAttention camp remains competitive. This is a live contest, not a closed verdict.

That is the end of the Attention arc — from the scaled dot product through the quadratic wall and its dozen escapes to a frontier model that assembles them all. The next chapters are the rest of the transformer: the feed-forward network, normalization, mixture-of-experts, positional encodings, and the training and post-training that turn this machinery into something that talks back.
