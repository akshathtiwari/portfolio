A small window, a deep stack, an endless cache

Let each token attend only to the last few thousand — a fixed window. It looks like a hard limit on context, but stacking layers turns a width-W window into an L×W receptive field: information hops one window per layer, like a CNN. And because a token never looks past W, the KV cache is a fixed-size rolling buffer that never grows, no matter how long you generate.

Longformer and BigBird paired a local window with global tokens to reach far. Mistral 7B (Jiang et al., 2023) made a leaner bet for a decoder language model: drop the global tokens entirely, keep only the sliding window, and let network depth do the long-range reaching. It works, and it comes with an inference bonus that is arguably the bigger deal — a KV cache that stops growing.

Sliding Window Attention (SWA): each token attends to itself and the previous W−1W-1W−1 tokens — a window of size WWW (4096 in Mistral 7B) — and nothing older. Compute is O(n⋅W)O(n \cdot W)O(n⋅W), linear in sequence length. So far this is just Longformer's local half. The insight is what depth does to it.

The one idea

A width-WWW window looks like a hard WWW-token memory limit, but it isn't: after LLL stacked layers a token's receptive field is L⋅WL \cdot WL⋅W, because each layer lets information hop one window forward — exactly a CNN's growing receptive field. And since no token ever attends past WWW, the KV cache is a fixed-size rolling buffer of length WWW — constant memory at any context length.

Depth buys range

Here is the mechanism. In layer 1, token iii reads tokens [i−W+1, i][i-W+1,\, i][i−W+1,i] directly. But the representation of token i−W+1i-W+1i−W+1 that it reads has, in that same layer's input, already absorbed its window [i−2W+2, i−W+1][i-2W+2,\, i-W+1][i−2W+2,i−W+1] from the previous layer. So by layer 2, token iii is indirectly influenced by tokens up to 2W2W2W back; by layer kkk, up to k⋅Wk \cdot Wk⋅W:

The rolling KV cache

Now the inference payoff, which may matter more than the compute. In full attention, generating token nnn means storing and re-reading the keys/values of all n−1n-1n−1 previous tokens — a KV cache that grows without bound (the memory-bound bottleneck from the MQA/GQA post). With sliding-window attention, a token only ever attends to the last WWW keys, so you never need to store more than WWW of them. The cache becomes a fixed-size rolling buffer: the key/value for timestep iii is written to slot i mod Wi \bmod WimodW, overwriting the entry from i−Wi - Wi−W, which is now out of every future token's window anyway.

cache slot for token i=i mod W,cache size=W (constant, for any n).\text{cache slot for token } i = i \bmod W, \qquad \text{cache size} = W \ \text{(constant, for any } n).cache slot for token i=imodW,cache size=W (constant, for any n).

What it costs

  • Beyond L×W is truly gone. The receptive field is a hard ceiling — information older than L⋅WL \cdot WL⋅W tokens cannot reach the current position at all. Unlike full attention, there is no path to arbitrarily distant context.
  • Reaching far is indirect and lossy. Long-range influence arrives through many window hops, each of which mixes and compresses; precise recall of a specific token thousands of positions back is weak compared to full attention's direct link. Later Mistral models mix in full-attention layers partly for this reason.
  • It's a local approximation. Good enough for the mostly-local dependencies of language, but not for tasks that need exact, sharp long-range retrieval — where you want full attention (made cheap by FlashAttention) or a hybrid.

Where this sits in the lineage

Sliding-window attention is the local window of Longformer/BigBird, promoted to the whole mechanism for a decoder LM and paired with its killer inference feature, the rolling cache. In practice it rides alongside grouped-query attention (Mistral 7B uses both) — SWA caps the cache length at WWW, GQA shrinks its per-token size — and modern models increasingly hybridize: some sliding-window layers for cheap local mixing, some full-attention (or linear-attention) layers for global recall. That hybrid instinct — cheap local plus a little expensive global — is exactly the shape of frontier long-context designs, right up to Kimi K3.
