Phase 1 · Attention  /  efficient · Mamba & SSMs

Stop storing every token. Keep a smart summary.

Attention keeps a perfect transcript of the past — the KV cache — and re-reads all of it every step, which is why it costs O(n²). State-space models do the opposite: compress all history into a fixed-size state, O(1) memory, O(n) compute. The catch is forgetting. Mamba's fix is to make the state selective — the model learns, per token, what to keep — recovering content-based memory at linear cost.

Every method so far still computed attention — sparser, lower-rank, kernelized, or IO-optimized, but attention. The most radical escape abandons it and returns to the recurrence attention replaced — but a recurrence redesigned to be linear (so it trains in parallel) and, in Mamba, selective (so it can actually compete on language). This is the branch that might replace attention rather than accelerate it.

The one idea

A state-space model summarizes all history into a fixed-size state updated by a linear recurrence — O(1) memory per step, O(n) total, no growing cache. Classic SSMs lost to attention on language because their fixed dynamics forgot indiscriminately. Mamba's insight: make the state update input-dependent (selective), so the model decides what to remember or forget based on the token it's reading — content-based memory, at linear cost.

The state-space recurrence

An SSM maps an input sequence to an output through a hidden state hth_tht​, with a linear update and a linear readout:

ht=A ht−1+B xt,yt=C ht.h_t = A\,h_{t-1} + B\,x_t, \qquad y_t = C\,h_t.ht​=Aht−1​+Bxt​,yt​=Cht​.

It is an RNN, but a linear one. The state hth_tht​ is a fixed-size vector that carries a compressed summary of everything seen so far; to produce the next output you only need the current state and the new token — so inference is O(1) per step in memory, no cache that grows with context. That is the property that makes SSMs so attractive for very long sequences.

Why it can also train in parallel

A plain RNN is sequential — a training nightmare. But because this recurrence is linear and (in classic SSMs) time-invariant (A,B,CA, B, CA,B,C constant), unrolling it gives a convolution: the output is the input convolved with a fixed kernel derived from A,B,CA, B, CA,B,C. Convolutions parallelize across the whole sequence like a transformer. So structured SSMs (S4 and successors) got the best of both worlds — recurrent at inference (O(1) state), convolutional at training (parallel, O(n)).

But "time-invariant" hides the flaw that kept SSMs out of language modeling.

The flaw, and Mamba's selection

Fixed A,B,CA, B, CA,B,C means the model applies the same dynamics to every token, regardless of content. It cannot say "this token is important — write it to memory" or "this is filler — ignore it" or "reset, a new topic starts." That content-blindness is fine for smooth signals (audio, time series) but fatal for language, which is all about selectively remembering the right earlier token — exactly the content-addressable memory that made attention win. Time-invariant SSMs underperformed transformers on text for this reason.

Mamba (Gu & Dao, 2023) fixes it with a selection mechanism: make the step size Δ\DeltaΔ and the matrices B,CB, CB,C functions of the input xtx_txt​. Now the state update is content-dependent — the model gates information into and out of the state based on what it is currently reading, so it can selectively remember, ignore, or reset. This recovers the selective memory attention provided. Watch a fixed vs a selective state try to hold one important token through a stream of filler:

The catch: selection breaks the convolution

Input-dependent Δ,B,C\Delta, B, CΔ,B,C mean the recurrence is no longer time-invariant — and the convolution trick, which required a fixed kernel, is gone. Mamba can't train as a convolution anymore. Instead it computes the (now input-varying) linear recurrence with a hardware-aware parallel scan: an associative-scan algorithm that still parallelizes across the sequence, fused into a GPU kernel that keeps the state in fast SRAM and recomputes intermediates in the backward pass — the same IO-aware discipline as FlashAttention. So Mamba stays parallel and fast despite giving up the convolution.

The payoff Mamba scales linearly in sequence length, keeps a constant-size state at inference (roughly 5× higher generation throughput than a comparable transformer, since there is no growing KV cache to stream), and matches or beats transformers of the same size on language, audio, and genomics — while handling sequences up to a million tokens. It was the first SSM to genuinely rival attention on language.

What it costs

  • A fixed state is still lossy. Even selective, an O(1) state cannot store arbitrary detail about every past token the way attention's cache can. On tasks demanding exact retrieval of a specific earlier token (associative recall, precise copying), attention still has an edge — the compression that buys efficiency also loses information.
  • Hence hybrids. Many strong models interleave attention and SSM layers: a few attention layers for sharp recall, many Mamba layers for cheap long-range mixing. The two are complementary, not strictly competing — and this is exactly the design space frontier models now explore.
  • The kernel is custom. The selective scan needs a bespoke hardware-aware implementation; it is not the drop-in that FlashAttention was for existing transformers.

Where this sits in the lineage

Mamba is the abandon-attention branch — and it is closer to the linear-attention line than it first looks. A linear-attention model's running key–value summary is a fixed-size recurrent state; Mamba-2 (2024) made this precise, showing a duality between selective SSMs and a form of linear attention. So the two most radical efficiency lines — kernel/linear attention and selective state spaces — converge on the same object: a fixed-size state you update and read, instead of a cache you grow and re-scan. That convergence is exactly where the frontier lives: Kimi K3's efficient core is a linear-attention mechanism (Kimi Delta Attention) in this same family, typically hybridized with full-attention layers to keep the recall that a pure fixed state gives up. Compress the past, but learn what to keep.
